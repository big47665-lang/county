# Telegram Counter Bot

بات تلگرام با دو قابلیت:
1. دستور `/count عدد` توی گروه — شمارش از ۱ تا عدد داده‌شده (حداکثر ۲۵)، هر ۳۰ ثانیه یک پیام، با محدودیت هر ۳۰ دقیقه یک‌بار برای هر کاربر.
2. پیام خودکار ساعتی — هر ساعت یکی از ۴ جمله‌ی از پیش تعریف‌شده برای اون ساعت، رندوم انتخاب و به همه‌ی گروه‌هایی که بات توشونه فرستاده میشه.

تمام متن‌ها (پیام خوش‌آمد، متن شمارشگر، پیام‌های ساعتی) توی فایل `config/phrases.js` قابل ویرایش هستن — بدون نیاز به دست‌زدن به کد اصلی.

## مرحله ۱: ساخت بات در تلگرام

1. توی تلگرام به [@BotFather](https://t.me/BotFather) پیام بده.
2. `/newbot` رو بزن و اسم و یوزرنیم بات رو انتخاب کن.
3. توکنی که بهت میده رو نگه دار (چیزی شبیه `123456789:ABCdefGhIJKlmNoPQRstuVwXyz`).
4. مهم: به BotFather دستور `/setprivacy` رو بزن، بات رو انتخاب کن و روی **Disable** بذار. این کار لازمه تا بات بتونه دستور `/count` رو داخل گروه ببینه.

## مرحله ۲: آپلود روی گیت‌هاب

1. یه ریپازیتوری جدید توی گیت‌هاب بساز.
2. تمام فایل‌های این پوشه رو (به‌جز `node_modules` و `.env`) داخلش push کن.

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin <آدرس ریپازیتوری خودت>
git push -u origin main
```

## مرحله ۳: دیپلوی روی Railway

1. وارد [railway.app](https://railway.app) شو و با گیت‌هاب لاگین کن.
2. **New Project → Deploy from GitHub repo** رو بزن و ریپازیتوری‌ات رو انتخاب کن.
3. توی تب **Variables** یه متغیر جدید بساز:
   - Key: `BOT_TOKEN`
   - Value: توکنی که از BotFather گرفتی
4. Railway به‌صورت خودکار `npm install` و `npm start` رو اجرا می‌کنه.

نکته درباره‌ی دائمی بودن داده‌ها: این پروژه لیست گروه‌ها و کول‌داون‌ها رو توی یه فایل به اسم `data.json` ذخیره می‌کنه. روی Railway، اگه سرویس ری‌استارت بشه و Volume دائمی وصل نکرده باشی، این فایل پاک میشه (یعنی باید بات رو دوباره از گروه حذف و اضافه کنی). اگه می‌خوای دائمی بمونه، از تب Settings سرویس، یک **Volume** اضافه کن و مسیر `DATA_FILE` توی `index.js` رو به اون مسیر تغییر بده.

## مرحله ۴: اضافه کردن بات به گروه

1. توی تلگرام به بات پیام بده و `/start` بزن — یه راهنمای فارسی می‌فرسته.
2. بات رو به گروه دلخواهت اضافه کن.
3. توی گروه دستور رو امتحان کن:
   ```
   /count 10
   ```

## ویرایش متن‌ها

فایل `config/phrases.js` رو باز کن:

- `startMessage` → متن پیام خصوصی `/start`
- `counterPhrase` → متنی که کنار هر عدد توی `/count` فرستاده میشه
- `hourlyPhrases` → آرایه‌ای با ۲۴ عضو (یکی برای هر ساعت ۰۰ تا ۲۳)، هر عضو شامل ۴ جمله؛ هر ساعت یکی از این ۴ جمله رندوم انتخاب میشه.

بعد از ویرایش، فقط کافیه commit و push کنی؛ Railway به‌صورت خودکار نسخه‌ی جدید رو دیپلوی می‌کنه.

## اجرای لوکال (تست قبل از دیپلوی)

```bash
npm install
cp .env.example .env
# توکن رو داخل .env بذار
npm start
```
